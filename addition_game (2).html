📐 Lesson 2 Step 2 of 3

Tens and Ones Columns

When we add two-digit numbers, we line them up by their TENS and ONES.

Column Method

TENS ONES
2 3
1 4
3 7
🟥 Tens: 2 + 1 = 3
🟦 Ones: 3 + 4 = 7
✅ Answer: 37
🚫
No Carrying! Each column's answer must be 0–9. If ones add up to 10 or more — that's a harder problem for later! Today, we keep it simple.

📋 Key Takeaways Review

🌟 What We Learned

1
Addition joins numbers. We use + to add two groups together and find the total.
2
Tens and Ones columns. Line up digits carefully — tens above tens, ones above ones.
3
Add each column separately. Ones + Ones first, then Tens + Tens.
4
No carrying needed! When we add without carrying, each column answer is 0–9. Keep it simple! 😊
5
Practice makes perfect! The more we practice, the faster and stronger our math skills grow. ⭐
