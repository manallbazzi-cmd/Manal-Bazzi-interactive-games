📚 Key Takeaways

  • Digit Form: This is how we write the number using digits (0-9)
  • Word Form: This is how we say and write the number in words
  • Expanded Form: This shows the value of each digit (tens + ones)
  • Tens: Groups of 10 (like 20 = 2 tens)
  • Ones: Individual units (like 3 ones)
  • Numbers up to 69 have up to 6 tens and up to 9 ones!
